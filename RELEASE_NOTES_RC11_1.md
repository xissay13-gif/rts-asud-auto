# RC11.1 — маршрут feedback по качеству коммунальных услуг

- Письма feedback с точной категорией «Качество коммунальных услуг»
  назначаются только Жукову Ивану Сергеевичу.
- Служебный цифровой код категории в конце, например `[84]`, при сравнении
  игнорируется.
- Другие категории feedback продолжают использовать обычный список адресатов.
- Поиск выполняется только по структурному полю «Тема вопроса», а не по
  свободному тексту обращения.
- Маршрут доступен в `settings.json` через `feedback_addressee_routes`.

Версия включает изменения RC10 и RC11: исключение восьми тем ГИС ЖКХ из
регистрации и автоматическое закрытие системного уведомления АСУД.

Проверка: 141/141 автоматический тест.
