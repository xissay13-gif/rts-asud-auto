# Временные диагностические логи АСУД

Репозиторий публичный. Перед загрузкой удалите из лога ФИО, адреса,
телефоны, номера документов, сетевые пути, логины, токены и другие
персональные или служебные данные.

Загружайте только обезличенные `.txt`/`.log`. Файлы `.msg` сюда
загружать нельзя. После разбора диагностический лог удаляется из ветки.
