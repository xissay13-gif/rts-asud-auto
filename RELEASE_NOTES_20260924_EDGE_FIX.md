# Исправление запуска Edge — 24.09.2026

Исправлена ошибка `ModuleNotFoundError: No module named
'selenium.webdriver.edge.webdriver'` при запуске прикрепления ответов.
Модуль браузера теперь импортируется явно и включается в EXE.

Теперь это отдельная программа `asud_reports.exe` с одним батником
`Прикрепление_отчетов.bat`. В комплекте только прикрепление отчётов;
выбор режима регистрации и другие батники отсутствуют.

Распакуйте комплект в отдельную папку и поместите туда совместимый
`msedgedriver.exe`. Можно перенести существующий `settings.json`:
программа использует раздел `reply_reports`. Журнал `.asud_replies.json`
в папке ответов оставьте на месте, чтобы сохранить защиту от повторов.

Проверка сборки: `scripts/smoke_frozen_edge.py` запускает именно собранный EXE,
открывает локальную страницу в Edge и выполняет прикрепление отчётов
с пустой папкой. Рабочая АСУД и файлы ответов при проверке не используются.

В исходном проекте сохранены отдельные сценарии регистрации и выдачи резолюций;
они не входят в новую сборку для начальников отделов.
