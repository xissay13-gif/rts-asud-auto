# Исправление зависания АСУД на архивах

- Внешний ZIP больше не прикладывается к карточке АСУД.
- Письмо преобразуется в один файл EML.
- Внутри EML находятся `Обращение.docx` и все исходные вложения письма.
- Старое значение `"msg_attachment_mode": "zip"` автоматически использует
  новый EML-режим, поэтому существующий `settings.json` можно не менять.
- На Windows EML открывается в Outlook, на Astra Linux — в Thunderbird или
  другом почтовом клиенте.
- Исходный MSG по-прежнему удаляется или переносится только после успешной
  регистрации документа.

Для ручной диагностики старый формат оставлен под отдельным значением
`"msg_attachment_mode": "zip-legacy"`, использовать его в боевой работе не
следует.
