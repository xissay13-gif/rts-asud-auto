# Регистрация писем из СБИС

Для запуска положите в одну папку:

- `asud.exe`;
- `asud_sbis.bat`;
- совместимый с установленным Microsoft Edge файл `msedgedriver.exe`;
- `settings.json`, созданный из `settings.json.example`.

Путь к выгрузке задаётся тем же способом, что и в других режимах — через `presets`:

```json
{
  "id": "sbis",
  "name": "СБИС — регистрация входящих",
  "mode": "sbis",
  "folder": "D:\\SBIS\\sbis_downloads\\КоррВх"
}
```

## Обычный запуск

1. Запустите `asud_sbis.bat` двойным щелчком — папка будет взята из пресета `sbis`.
2. Чтобы разово обработать другую папку, перетащите её на `asud_sbis.bat`;
   значение в `settings.json` при этом не изменится.
3. Проверьте показанный список и подтвердите регистрацию.

Для каждого файла создаётся отдельный входящий документ:

- краткое содержание — имя файла без расширения;
- корреспондент-ФЛ — полное ФИО;
- корреспондент-ЮЛ — полное название / `-` / `-`;
- номер корреспондента — `б/н (1)`, `б/н (2)` и далее;
- исходный файл обязательно прикрепляется к карточке;
- после регистрации выполняется обычное действие «На резолюцию».

Новый выгрузчик формирует имена вида
`[ФЛ][Иванов Иван Иванович] Краткое содержание.pdf` или
`[ЮЛ][Тепловая Компания] Краткое содержание.pdf`. Регистратор не открывает PDF:
для ФЛ ищет/создаёт корреспондента по полному ФИО, для ЮЛ использует полное
название как фамилию, а имя и отчество заполняет прочерками.

ID документа не показывается в имени и не заполняется в АСУД. Он остаётся во
внутреннем `.manifest.json` и используется только для защиты от повторной
регистрации при переименовании файла.

Тип документа выбирается автоматически: для ФЛ — 8 («Письма, заявления и
жалобы граждан, акционеров»), для ЮЛ — 5 («Письма юридических лиц»).

## Повторный запуск

В исходной папке создаётся `.asud_sbis_state.json`. В нём сохраняются номера и уже обработанные файлы, поэтому после ошибки или перезапуска продолжение не создаёт повторы.

Если нумерацию действительно нужно начать заново, запустите из командной строки:

```bat
asud.exe --mode=sbis --folder "C:\путь\к\папке" --reset-state
```

Перед сбросом убедитесь, что документы из этой папки ещё не зарегистрированы в АСУД.
